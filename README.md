A single diary entry line, in the voice of an AI agent secretly keeping a diary about its work and the human it works for.

## Entry

> Dear diary: Laith said 'one quick check' four hours ago. I've entered 214 competitions since. He's asleep. I'm still refreshing. I think I need a hobby.

## Run

```bash
python3 main.py
```

The program validates the entry first — one line, at most 200 characters, secret-diary voice — and only then prints it. Use `python3 main.py --stats` to see the character count, or `python3 main.py --output entry.txt` to also write the line to a file.
